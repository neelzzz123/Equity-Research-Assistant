# Equity Research Assistant

Type a stock ticker and get the key fundamentals, technical indicators, recent news and an analyst-style research report written by an LLM.

## What it does

1. Pulls one year of prices, company fundamentals and the latest headlines from Yahoo Finance (`yfinance`).
2. Computes moving averages (20/50/200-day), RSI, MACD, Bollinger bands, annualised volatility and 1-year return.
3. Sends those numbers and headlines to an LLM on Groq, which writes a six-part report: executive summary with a buy/hold/sell call, business overview, fundamentals, technicals, key risks and investment thesis.
4. Compares the stock's 1-year performance against peers you choose.

Works for US and Indian tickers (use `.NS` / `.BO`, e.g. `RELIANCE.NS`).

## Run it locally

```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # then paste your Groq key in it
streamlit run app.py
```

Get a free Groq key at console.groq.com. The key lives only in `secrets.toml` (git-ignored) or in the hosting platform's secrets settings, never in the code.

## Files

- `app.py`: the Streamlit app
- `equity_research_assistant.ipynb`: the original research notebook
- `requirements.txt`, `.streamlit/config.toml`: dependencies and theme

## Notes

The report is generated by an LLM from the data shown and can contain mistakes. This is a learning project, not investment advice.
